# 图片水印添加工具

## 简介

批量为图片添加文字/图片水印，支持透明度、位置、旋转角度自定义，保护你的原创图片！

## 功能特性

- ✅ **批量处理**：一次添加数百张图片水印
- ✅ **文字水印**：自定义字体、颜色、大小
- ✅ **图片水印**：支持 PNG 透明水印
- ✅ **位置控制**：9 宫格位置选择
- ✅ **透明度调节**：0-100% 自由设置
- ✅ **旋转角度**：自定义旋转角度

## 使用场景

- 摄影师作品保护
- 电商图片防盗用
- 设计稿版权标记
- 社交媒体图片签名

## 系统要求

- Windows 10/11 或 macOS 10.15+
- 2GB RAM 以上
- 200MB 可用磁盘空间
- 支持 JPG/PNG/WEBP 格式
