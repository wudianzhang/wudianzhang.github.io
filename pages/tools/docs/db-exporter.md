# 数据库导出精灵

## 简介

支持 MySQL/SQLite/PostgreSQL 一键导出为 Excel/CSV/JSON，定时备份、字段筛选、格式自定义！

## 功能特性

- ✅ **多数据库支持**：MySQL、SQLite、PostgreSQL
- ✅ **多种格式导出**：Excel、CSV、JSON、SQL
- ✅ **定时备份**：自动定时导出数据备份
- ✅ **字段筛选**：自定义导出字段
- ✅ **数据过滤**：支持 WHERE 条件过滤
- ✅ **批量导出**：多个表同时导出

## 使用场景

- 数据库定期备份
- 数据迁移准备
- 报表数据提取
- 开发测试数据生成

## 系统要求

- Windows 10/11 或 Linux
- 2GB RAM 以上
- 支持 MySQL 5.7+ / SQLite 3+ / PostgreSQL 12+
