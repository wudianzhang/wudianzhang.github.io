# 文件批量重命名大师

## 简介

一键批量重命名文件，支持规则替换、序号递增、日期前缀等多种模式，告别手动改名烦恼！

## 功能特性

- ✅ **批量处理**：一次处理数百个文件
- ✅ **多种模式**：替换、序号递增、日期前缀、正则表达式
- ✅ **预览功能**：实时查看重命名效果
- ✅ **撤销操作**：一键恢复原始文件名
- ✅ **跨平台**：支持 Windows 和 Mac

## 使用方法

### 基础模式

1. 选择要重命名的文件或文件夹
2. 设置重命名规则
3. 点击预览查看效果
4. 确认后执行重命名

### 高级模式

- 使用正则表达式进行复杂匹配
- 自定义序号格式（如 `001`, `A001`）
- 添加日期/时间戳前缀或后缀

## 系统要求

- Windows 7/10/11 或 macOS 10.15+
- 2GB RAM 以上
- 100MB 可用磁盘空间
